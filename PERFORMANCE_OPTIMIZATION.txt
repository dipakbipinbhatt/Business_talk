💡 CACHING STRATEGY:

   File Type          Cache Duration    Strategy
   ────────────────────────────────────────────────
   Images/Fonts       1 year            Immutable
   CSS/JS             1 year            Immutable
   HTML               1 hour            Revalidate
   API Responses      No cache          Fresh data

   Why 1 year for CSS/JS?
   - Vite adds hash to filenames
   - New deploy = new filename
   - Old files never change
   - Safe to cache forever
