========================================
🚀 ONE COMMAND TO FIX EVERYTHING
========================================

Copy and paste this SINGLE command on your server:

sudo systemctl stop nginx && sudo systemctl disable nginx && cd ~/Business_talk && docker-compose -f docker-compose.prod.yml down && docker-compose -f docker-compose.prod.yml up -d && sleep 15 && docker ps && echo "" && echo "✅ DONE! Test your site: http://68.178.161.128"

========================================
OR use the script:
========================================

cd ~/Business_talk
bash PERFECT_FIX.sh

========================================
WHAT THIS DOES:
========================================

1. ✅ Stops nginx on host (freeing port 80/443)
2. ✅ Stops old Docker containers
3. ✅ Starts fresh Docker containers
4. ✅ Backend runs on port 5000
5. ✅ Frontend runs on port 80
6. ✅ Your site is back online!
