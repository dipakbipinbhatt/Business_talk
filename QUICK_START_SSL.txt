   4. Deploy:
      docker-compose -f docker-compose.prod.yml down

      docker ps

   Solution: docker logs business-talk-frontend
            Check if SSL files exist: ls -la ~/Business_talk/ssl/

   Problem: Certificate error in browser
   Solution: Verify certificate:
            openssl x509 -in ~/Business_talk/ssl/fullchain.crt -text -noout

   Problem: API not working
   Solution: Check backend logs:
            docker logs business-talk-backend

   Problem: Mixed content warnings
   Solution: Clear browser cache and hard reload (Ctrl+Shift+R)
