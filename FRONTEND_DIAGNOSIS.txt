========================================
COMMON ISSUES & SOLUTIONS
========================================

ISSUE 1: "10-listen-on-ipv6-by-default.sh: info: /etc/nginx/conf.d/default.conf differs from the packaged version"

This is NORMAL! It means:
  ✅ Your custom nginx config is being used
  ✅ Not an error, just informational message
  ✅ Nginx is working correctly

SOLUTION: No action needed - this is expected behavior


ISSUE 2: Frontend not accessible from browser

SOLUTION:
  1. Check if port 3000 is exposed:
     docker ps | grep frontend
     
  2. Check if nginx is listening:
     docker exec frontend netstat -tlnp | grep 80
     
  3. Test from server:
     curl http://localhost:3000
     
  4. Check firewall:
     sudo ufw status


ISSUE 3: "Connection refused" when accessing frontend

SOLUTION:
  1. Restart frontend container:
     docker restart frontend
     
  2. Check docker-compose.yml ports:
     Should have: "3000:80"
     
  3. Rebuild if needed:
     docker-compose up -d --build frontend


ISSUE 4: Frontend shows blank page

SOLUTION:
  1. Check if build files exist:
     docker exec frontend ls /usr/share/nginx/html/
     
  2. If empty, rebuild:
     docker-compose build --no-cache frontend
     docker-compose up -d frontend
     
  3. Check browser console for errors
